# MUSE — ИИ-стилист (ядро MVP)

PWA: гардероб из фото (фон удаляется автоматически), подбор 3–4 образов под событие и почасовую погоду,
календарь, напоминания, чемодан в поездку, тип фигуры. React + TypeScript + Vite + Supabase.

## Запуск

```bash
cp .env.example .env.local   # вписать URL и publishable key Supabase
npm ci
npm run dev
```

Проверки: `npm test` (движок подбора и погода), `npm run lint`, `npm run build`.

Чтобы заработали база, фото, ИИ и уведомления, нужно один раз настроить Supabase — см. [AI-SETUP.md](AI-SETUP.md).
Без развёрнутых Edge Functions приложение работает: образы подбираются по правилам прямо на устройстве.

## Где что

| Путь | Что |
|---|---|
| `src/App.tsx` | состояние, сохранение, связи между экранами |
| `src/pages/` | Сегодня, Календарь, Гардероб, Чемодан, Профиль |
| `src/components/` | загрузка фото, карточка вещи, подбор образов, событие, поездка, фигура, вход |
| `src/lib/weather.ts` | прогноз Open-Meteo, сводка на интервал события, климат для поездок |
| `src/lib/background.ts` | удаление фона → вещь на белом фоне |
| `supabase/functions/_shared/stylist.ts` | движок подбора: фильтры, правила, «цена образа», чемодан, советы |
| `supabase/functions/*` | ИИ-подбор, распознавание вещи, фигура по фото, удаление аккаунта, напоминания |
| `supabase/migrations/` | таблицы, RLS, закрытый бакет фото, сводки аналитики и расходов |
| `CLAUDE.md` | решения и структура данных |
